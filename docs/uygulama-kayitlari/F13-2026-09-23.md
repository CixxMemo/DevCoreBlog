## Ne ve neden değişti?

Yönetim formları jQuery Validation eklentilerini jQuery yüklenmeden çalıştırdığı için Create/Edit ekranları konsolda `jQuery is not defined` hatası üretiyor ve istemci doğrulaması devreye girmiyordu. Ortak validation partial'ı yerel jQuery 3.7.1, jQuery Validation 1.21.0 ve Unobtrusive Validation 4.0.0 dosyalarını bu bağımlılık sırasıyla ve yalnız form sayfalarında birer kez yüklüyor. Login formu bu eklentilere ihtiyaç duymadığı için ek yük taşımıyor.

Yazı içeriği textarea'sı artık çalışan HTML taban çizgisidir. Toast UI başarıyla başlatılırsa küçük ortak yardımcı editörü gösterip textarea'yı gizler ve Markdown değerini her değişiklikte alana eşler. Toast UI veya yardımcı script çalışmazsa textarea görünür ve düzenlenebilir kalır. Böylece JavaScript kapalıyken de form kaydı yapılabilir; zengin editör açıkken gizlenen Content alanı istemci doğrulamasından kaçmaz.

`_AdminLayout` incelendi; sayfaya özel `Scripts` bölümünü gövde sonunda tek kez ürettiği için global jQuery eklemeye veya layout'u değiştirmeye gerek kalmadı. F30 kapsamındaki büyük Create/Edit script birleştirmesi yapılmadı; F13 yalnız editörün güvenli başlatma/senkronizasyon sınırını ortaklaştırdı.

## Değişen dosyalar

- `Views/Shared/_ValidationScriptsPartial.cshtml`: üç yerel asset'i doğru sıraya aldı; Content textarea'sını gizliyken de doğrulayan dar jQuery ayarı eklendi.
- `Views/AdminPost/Create.cshtml`, `Edit.cshtml`: textarea çalışan fallback haline getirildi; Toast UI ortak yardımcı üzerinden progressive enhancement olarak başlatıldı.
- `wwwroot/js/admin-post-editor.js`: editörü yalnız bağımlılıklar hazırsa açan ve Markdown değerini form alanına eşleyen küçük, tek sorumluluklu yardımcı.
- `scripts/verification/f13_frontend_validation_probe.py`: script sırası/tekillik, mesaj eşliği, fallback HTML ve JavaScript'siz gerçek kayıt regresyonu.
- `scripts/verification/run_f01_baseline.sh`: F13 probe'u birleşik izole koşuya eklendi.
- `docs/GELISTIRME_PLANI_2026-09-21/DURUM.md`: ilerleme ve sıradaki faz güncellendi.

- **SOLID ve sadelik:** Asset sırası tek partial'da; editör başlatma/fallback sorumluluğu küçük ortak modülde. Yeni framework, form motoru, vendor veya gereksiz interface eklenmedi.
