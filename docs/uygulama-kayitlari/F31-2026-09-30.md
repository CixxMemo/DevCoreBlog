## Ne ve neden değişti?

Create için mevcut yerel anahtar, her Edit için yazı ID'sine bağlı ayrı anahtar
kullanılıyor. Başlık, Markdown içerik, kategori, özet, alıntı, yayın zamanı ve iki
checkbox 300 ms debounce ile tarayıcıda saklanıyor. Dosya, parola, cookie,
antiforgery token, kapak URL'si ve edit concurrency sürümü saklanmıyor.

Farklı kurtarma kopyası varsa sunucu metni korunuyor ve Restore/Discard seçimi
sunuluyor. Boş alanlar da doğru geri yükleniyor; eski Create biçimi açık Restore
ile yeni biçime geçiyor. Bozuk kopya otomatik ezilmiyor. Scratchpad aktarımı da
sessizce formu doldurmak yerine seçim olarak sunuluyor.

Submit kopyayı silmiyor. Yerel sürüm kimliği forma ekleniyor; controller ancak
başarılı service sonucu sonrasında korumalı TempData üzerinden tek kullanımlık
başarı bilgisi üretiyor. Index'teki modül yalnız anahtar ve sürüm hâlâ eşleşiyorsa
kopyayı temizliyor. Başarısız doğrulama veya 409 bu bilgiyi üretmiyor. Query string
başarı bilgisi oluşturamıyor. Diğer yazı ve daha yeni sekme kopyaları korunuyor.

Yerel okuma/karşılaştırma/yazma/temizleme aynı anahtarın exclusive Web Lock'u
altında çalışıyor. Sekme başka bir kopya görürse yerel kaydı durdurup seçim istiyor;
formdaki mevcut metni değiştirmiyor. API davranışı [W3C Web Locks](https://www.w3.org/TR/web-locks/)
kaynağından doğrulandı. Web Locks yoksa güvensiz yarışlı yazma yapılmıyor; yerel
kurtarma kullanılamaz bildirimiyle normal MVC kaydı devam ediyor. Storage erişimi
veya kota hatası da native form gönderimini engellemiyor.

İlk HTTP kontrolünde başarı bilgisi görünmedi: mevcut TempData serializer'ı GUID
biçimli string'i redirect sonrasında Guid olarak geri getiriyordu. Görünümdeki
`as string` kaldırılıp scalar `ToString()` kullanıldı; son temiz fixture'da bütün
başarı/başarısızlık kontrolleri tekrar geçti. Hatalı kontrol başarı sayılmadı.

## Veri ve geri dönüş

- Kalıcı etki yalnız tarayıcının localStorage kurtarma biçimidir; eski Create metni otomatik silinmiyor.
- Gerçek DB, production hesap veya credential kullanılmadı. İzole test DB/kopyaları ve test sekmeleri kapatıldı; kendi build/Python cache çıktıları kaynak diff'inden çıkarıldı.
- Geri dönüşte yalnız F31 davranışı kaldırılabilir; kullanıcı metinleri saklanmalı ve kopyalanabilmeli. Submit-time silme geri getirilmemeli; eski Create interval'i kopyayı sessizce ezebilir.
- Depolama tarayıcı/origin ile sınırlıdır; dosyalar tekrar seçilir. Web Locks veya storage yoksa yerel kurtarma kullanılamaz, normal server save devam eder.
- 300 ms debounce dolmadan ani tarayıcı/process kapanmasında son tuşların saklanacağı garanti edilmez. Visibility değişiminde flush denenir; submit öncesinde flush beklenir.
- Canlı Cloudinary, production deploy, tüm tarayıcı sürümleri, gerçek ağ kopması ve 500 hata enjeksiyonu yapılmadı. Storage hata/normal submit test adaptöründe sınandı; gerçek tarayıcıda validation ve 409 sınandı. Başarı bilgisi olmadan silme yapılmadığı modül kontrolüyle doğrulandı.
