# F00 — Agent kuralları ve plan yenilemesi

**Tarih:** 21 Eylül 2026  
**Talep:** Kullanıcı eski Gemini kurallarının yenilenmesini, SOLID/temiz kod/güvenlik sınırlarının güçlendirilmesini, dosyaların agent tarafından bulunabilir konuma alınmasını ve planın güncellenmesini istedi.  
**Kural sürümü:** Kök AGENTS.md v2.  
**Durum:** TAMAMLANDI — yalnızca kurallar ve dokümantasyon.

## Ne ve neden değişti?

Ana kurallar repository köküne alındı; .agents/AGENTS.md tek kaynağa yönlendiriyor. Mevcut dört projeli MVC mimarisi, küçük webhook/feed sınırları ve güvenli input DTO/ViewModel kullanımı açıkça tanımlandı. SOLID'in beş ilkesi, spagetti kod yasağı, güvenlik, veri bütünlüğü, UI/UX, dependency ve test kuralları somut inceleme ölçütleriyle yazıldı.

Eski yedi plan ve ana talimatın orijinal içeriği arşivlendi. Aktif plandaki tek proje/entegrasyon kaldırma yolu çıkarıldı. F27'nin DTO silip manuel JSON ayrıştırma talimatı, küçük tipli input validation'ıyla değiştirildi. F12/F24/F25/F29/F41 ve ortak kurallar uyumlu hale getirildi. README'deki doğrulanmamış güvenlik/üretime hazır olma iddiaları düzeltildi.

## Başlangıç ve kullanıcı değişiklikleri

Görev başlangıcında .env.example, controller, view, helper, Program.cs, build çıktıları ve izlenmeyen webhook/feed dosyaları zaten değişmişti. Bunlar korunuyor. Uygulama kaynağı/config örneği için 945 dosyanın başlangıç SHA-256 özeti alındı; eski kurallar da arşive taşınmadan önce hash ile kaydedildi. Secret değerleri okunup rapora yazılmadı.

.agents korumalı dizin olduğu için kullanıcı talebini uygulayan dar kapsamlı dosya işlemi ortamın izin mekanizmasıyla çalıştırıldı. İşlem öncesi kaynak hash'leri ve arşiv kopyaları doğrulandı; yalnızca adı listelenmiş yedi eski plan kaldırıldı, köprü dosyası yazıldı.

## Doğrulama

Belge doğrulama komutu sıfır hata ile tamamlandı. Uygulama build/testi bu yalnızca-belge fazında çalıştırılmadı; F01'in kapsamıdır. Gerçek Codex ikinci oturumu başlatılmadı; yerleşim resmi keşif dokümanı, dosya varlığı, override kontrolü ve byte sınırıyla statik doğrulandı.

| Kontrol | Gerçek sonuç |
|---|---|
| Aktif belge bağlantıları ve code fence dengesi | 20 belge; hata yok. |
| Faz kimliği, gerekli kart alanları ve sıralı ön koşullar | F00–F57 arasında 58 benzersiz kart; doğru. |
| İlerleme | Yalnızca F00 tamamlandı; 57 faz başlamadı. |
| Eski karar dalları | Aktif planda eski A/B ve koşullu geçiş kimlikleri yok. |
| Talimat yerleşimi | Kök AGENTS.md mevcut; kökte override yok; .agents altında yalnızca yönlendirme var. |
| Repository talimat boyutu | Kök 21.055 byte + yönlendirme 776 byte; toplam 21.831 byte, varsayılan 32 KiB sınırının altında. |
| Başlangıç kaynak bütünlüğü | 945 dosyanın SHA-256 karşılaştırması aynı. |
| Eski talimatların arşiv bütünlüğü | 8 orijinal belge arşivi hash ile doğrulandı. Koşullu plan ayrıca arşivlendi. |

Bu sonuçlar aşağıdaki komutun gerçek çıktısından kaydedildi; build veya uygulama güvenlik testi sonucu değildir.

```sh
python3 docs/uygulama-kayitlari/F00-dogrulama.py \
  --source-baseline /tmp/devcore-rules-source-before.json \
  --archive-manifest /tmp/devcore-agents-migration-manifest.json
```

Bu iki /tmp dosyası görev başlangıcındaki geçici denetim verileridir. Sonradan yalnızca belge kontrolünü çalıştırmak için opsiyonel parametreleri çıkar; betik kaynak/arşiv kontrolü yapılmadığını null ile bildirir, geçmiş gibi göstermez.
