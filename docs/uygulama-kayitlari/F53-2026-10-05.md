## Ne ve neden değişti?

Sabit Connected/Cloudinary Active/Ready etiketleri kaldırıldı. Yetkili dashboard
DB kontrolü ve metrikleri süre sınırlı olarak okur; erişemiyorsa gerçek503 ve
Statistics unavailable gösterir. Sonuç yerine sıfır sayı uydurmaz. Data’nın dar
probe’u scoped bağlantıyı açar, mevcut sequential metrik sorguları yeniden kullanır.
Core/Services provider ayrıntısı bilmez; controller yalnız typed sonucu gösterir.

Cloudinary Configured credential varlığıdır, erişim kanıtı değildir. Eksik medya
config admin teşhisi kapatmaz; upload fail-closed503 kalır. Doğrulanmış tamamlanan
upload/son başarı tarihleri yalnız süreç içi UTC gözlemidir; DB save veya mevcut
sağlayıcı sağlığı değildir. Restart geçmişi sıfırlar. Webhook config yoksa401 kalır.
F26 eksik medya startup guard’ı bu yeni işlem sınırına göre güncellendi.

JSON console, server-assigned X-Request-ID/TraceId scope ve güvenli auth/upload/
webhook/global hata event’leri eklenir. EF/Npgsql ham error/SQL logları özel config
seviyesiyle açılamaz. İptal client crash sayılmaz; başlamış response hatası raw
exception’ı host loguna taşımadan bağlantıyı abort eder. Başlamamış hata500 kalır.
[Operasyon sözleşmesi](../OPERASYON_VE_LOG_SOZLESMESI.md) ayrıntıları ve Linux journal
hedefi/henüz canlıda doğrulanmayan retention/erişimi açıklar.
