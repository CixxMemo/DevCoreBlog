## Ne ve neden değişti?

Yönetici bildirimindeki mesaj artık HTML şablonuna eklenmiyor. Toast iskeleti güvenli DOM metotlarıyla oluşturuluyor ve kullanıcı/kayıt kaynaklı metin `textContent` ile atanıyor. Böylece yazı başlığı `<img onerror=...>` gibi görünse bile tarayıcı bunu element veya kod olarak yorumlamıyor.

Bildirim rozetleri ve CSS sınıfları yalnızca sabit success/error/info seçeneklerinden geliyor. Kapatma düğmesi inline `onclick` yerine `addEventListener` kullanıyor ve erişilebilir bir English etikete sahip. Toggle yanıtının mesaj alanı kullanılmadan önce string olduğu doğrulanıyor; beklenmeyen tipte sabit güvenli metin gösteriliyor.

## Değişen dosyalar

- `Views/Shared/_AdminLayout.cshtml`: `toast.innerHTML`, mesaj interpolasyonu ve inline `onclick` kaldırıldı; `createElement`, `textContent`, `append` ve `addEventListener` kullanıldı.
- `Views/AdminPost/Index.cshtml`, `Create.cshtml`, `Edit.cshtml`: JSON kaynaklı başarı/hata mesajlarına string tip sınırı ve sabit English fallback eklendi.
- `scripts/verification/f01_fixture.sql`: Yalnızca izole test DB'sinde kullanılan zararsız `<img onerror=...>` başlığı eklendi.
- `scripts/verification/f01_http_baseline.py`: F03 kaynak/sink kontrolleri eklendi; tamamlanmış F02 beklentisi korundu.
- `scripts/verification/run_f01_baseline.sh`: F03 kontrolü ve isteğe bağlı canlı tarayıcı fixture modu eklendi; temizleme tek seferlik hale getirildi.

Controller'ın mevcut JSON üretimi değiştirilmedi. `System.Text.Json.JsonSerializer.Serialize` ile üretilen TempData JavaScript değerleri korunuyor; bütün `showToast` çağrıları string veya açık string fallback kullanıyor.

## Kurallara uyum

- **Güvenlik:** Kullanıcı/kayıt metni HTML parser'a verilmez. `textContent` açık output sınırıdır; inline event handler kaldırıldı.
- **SOLID ve sadelik:** Tek global toast sorumluluğu kendi küçük fonksiyonunda kaldı; yeni kütüphane, framework veya gereksiz soyutlama eklenmedi.
- **Input sözleşmesi:** Toast yalnızca string kabul eder. AJAX yanıtı beklenmeyen tipteyse sabit English fallback kullanılır.
- **UI/UX:** Mevcut Tech Minimal görünüm, success/error/info ayrımı, otomatik kapanma ve manuel kapatma korundu. Kapatma düğmesi klavyeyle çalışır ve erişilebilir etikete sahiptir.
