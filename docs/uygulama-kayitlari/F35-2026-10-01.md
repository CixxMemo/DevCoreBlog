## Ne ve neden değişti?

Tarayıcıda çalışan Tailwind Play CDN kaldırıldı; CSS artık sabit sürüm ve lockfile ile build ortamında üretiliyor. Public ve admin layout'ların gerçek mevcut temaları ayrı çıktılara taşındı. Eski `wwwroot/tailwind.config.js` hiçbir layout'ta kullanılmıyor ve gerçek ayarlardan farklıydı; kaldırıldı.

CDN Tailwind bundle'ında `3.4.17`, Toast UI banner'ında `3.2.2` doğrulandı; Prism zaten `1.30.0` idi. Sürümler yükseltilmedi. Resmi küçük CLI yeterli; yeni framework/bundler kurulmadı. Toast UI npm paketi mevcut all-in-one dosyasını içermiyordu. Sabit CDN/SRI denemesinde gerçek tarayıcı editörü yükleyemedi; son uygulama aynı resmi dosyaları hash/lisanslarıyla yerelde sunar. Prism Toolbar CSS/JS eklendi ve Show Language'den önce yükleniyor; hatalı/olmayan Show Language CSS bağlantısı kaldırıldı. Autoloader mevcut yerel dizin yapısından dil dosyasını buluyor.

## Değişen dosyalar

- `package.json`, `package-lock.json`: Tailwind 3.4.17 ve Prism 1.30.0 exact bağımlılıkları; tek `npm run build` komutu.
- `frontend/tailwind*.cjs`, `frontend/tailwind.css`: Razor/JS literal sınıf taraması, mevcut public/admin font/renk/radius/dark davranışları.
- `frontend/vendor/toastui/*`: değişmeyen resmi 3.2.2 dağıtımı; MIT, DOMPurify ve ProseMirror lisans bildirimleri, kaynak ve SHA-256 kaydı. Microsoft bildirimi bundle içinde korunur.
- `scripts/frontend/build.mjs`: Node standart API'leriyle CSS derleme, yerel Prism/Toast UI ve lisansları üretme; yalnız kendi generated dizinini yeniden üretir.
- `DevCoreBlog.csproj`: build/publish entegrasyonu, npm kurulumu için lockfile timestamp kontrolü, node_modules/build kaynaklarını proje taramasından dışlama, temiz build'de üretilen varlıkları Content/publish'e ekleme.
- İki ana layout: yerel CSS/JS ve `asp-append-version`; mevcut CSS sırası ve temalar korundu.
- `.gitignore`, `README.md`: generated/npm klasörleri dışarıda, temiz checkout/build/run/publish talimatları.
- `scripts/verification/run_f35_assets.sh`, `f35_assets_probe.py`: geçici kaynak kopyasında tekrar üretim/publish ve gerçek rendered HTTP asset sözleşmesi.
- AGENTS.md, D04, F35 kartı, DURUM.md ve bu kayıt: kalıcı build sınırı ve doğrulanmış sonuçlar.
- Kanıt klasörü: [F35](kanit/F35). Tarihsel tracked bin/obj değişiklikleri yalnız bu çalışmanın ürettiği çıktılar olduğundan başlangıç Git içeriklerine geri getirildi; kaynak diff'ine eklenmedi. Depo temizliği F54'e bırakıldı.
